# 兔仔 · X 帖子浮层阅读器

[查看更新日志](CHANGELOG.md)

一个本地优先的 Chrome 扩展：在 X 时间线点击帖子正文时，不离开主页，直接打开一个左右双栏浮层。

> 本项目是社区维护的非官方工具，与 X Corp. 没有关联，也未得到其赞助或认可。X 和 Twitter 是其各自权利人的商标。

![浮层交互预览](docs/preview.png)

## 工作方式

扩展在页面启动时观察 X 自己的 GraphQL 请求，并从当前 X 页面运行时取得最新的帖子详情操作定义。Content Script 通过事件委托监听动态时间线；点击帖子时只保存一份作者、头像、时间和媒体 URL 的轻量 DOM 快照，用来补齐 GraphQL 偶尔缺失的字段，不会搬动或复制 X 的 React 节点。

- 左侧渲染原帖正文、媒体、网站预览卡片、X 长文完整正文、引用帖、时间、查看量和五项互动栏。
- 右侧渲染评论排序、纯文字回复框、真实评论、嵌套回复和加载更多。
- 点赞、转发、收藏和纯文字回复直接使用浏览器当前登录的 X 会话完成。
- 两栏各自滚动，关闭浮层后仍停留在原来的时间线位置。
- 视频优先使用扩展内置的 `hls.js` 播放 X 的自适应 HLS 流；没有 HLS 时再按当前网络选择适合的 MP4 码率。播放器始终显示明确的居中播放按钮，浮层内只保留一个视频同时播放。
- 界面图标从 Phosphor 官方 SVG 构建进扩展，不依赖 X 页面加载图标字体。

插件不使用 iframe、隐藏标签页、远程播放器脚本、硬编码 GraphQL `queryId` 或第三方服务器。`hls.js` 和许可证随扩展本地打包。X 的登录请求头和 CSRF 信息只在当前页面内存中使用，不写入扩展存储，也不会输出到日志。

## 现在能做什么

- 拦截时间线里的帖子正文点击并打开一个双栏浮层。
- 已经位于 X 帖子详情页时不拦截点击，继续使用 X 原生详情交互。
- 从通知等列表点击一条回复时，左侧会保留它所属的上文链，并把初始位置直接定位到被点击的当前回复；向上滚动即可查看完整上下文。
- 左侧显示原帖红线以上的正文、媒体、引用内容、数据和五项互动。
- 右侧显示红线以下的评论排序、回复框、评论列表和嵌套讨论。
- 支持相关、最新和最多喜欢三种本地排序，并用 X 的游标加载更多评论。
- 支持点赞/取消点赞、转发/取消转发、收藏/取消收藏、复制分享链接。
- 支持对原帖或某条评论发布 1 到 280 字的纯文字回复。
- 支持浅色、暗色和熄灯主题。
- GraphQL 缺少作者、头像、时间或媒体类型时，会用点击瞬间读取的 X DOM 数据补齐；已有 GraphQL 字段不会被覆盖。
- 浮层不修改 X 页面 `body/html` 的滚动方式；关闭时会恢复打开前的页面坐标。
- 单个视频按真实宽高比完整显示，引用帖不再使用固定 300px 高度裁切视频。
- 网站链接按 X 返回的标题、封面和来源域名显示预览卡片；X 长文会继续读取正文数据，在左侧直接展开完整文章，而不是停留在摘要卡片。
- 刚发布成功的纯文字回复会固定显示在当前评论列表顶部，并自动把评论区带回顶部，便于立即确认发布结果。
- `Esc`、遮罩或右上角按钮都可以关闭浮层。
- 插件工具栏里可以随时开启或关闭。

## 隐私与权限

扩展只申请：

- `storage`：保存开启/关闭状态。
- `x.com` / `twitter.com`：在 X 页面显示浮层，并使用当前登录会话读取和操作帖子。

扩展不申请 Cookie、标签页、DNR、webRequest、全站或其他网站权限，也没有第三方数据服务。登录请求头与 CSRF 信息只保留在 X 页面内存中。

## 本地开发

最低要求：Node.js 20+、npm 10+、Chrome 或其他 Chromium 浏览器。

Windows PowerShell：

```powershell
npm install
npm run test
npm run build
```

macOS / Linux / Git Bash：

```bash
npm install
npm run test
npm run build
```

开发预览：

```bash
npm run dev
```

## 加载到 Chrome

1. 执行 `npm run build:extension`。
2. 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择仓库里的 `dist-extension/`。
6. 首次加载或重新构建后，刷新已经打开的 X 标签页。

## 当前边界

- 回复编辑器只支持纯文字，不支持图片、视频、GIF、投票、草稿和高级 @ 提及建议；这些操作使用右上角“在 X 打开”。
- 评论“相关”沿用 X 返回的默认顺序；“最新”和“最多喜欢”只对当前已经加载的评论排序。
- X 内部 GraphQL 不是公开稳定 API。扩展会从当前页面动态发现操作定义，但 X 大改请求结构时仍可能需要更新解析器。
- 互动先在界面中乐观更新；如果 X 拒绝请求，会回滚并显示具体错误。
